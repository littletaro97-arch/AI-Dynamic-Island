# 设置交互与滚动性能修复（2026-10-11）

## 行为调整

- 修复速度滑块跳过滚动动画更新的问题。收起岛和可见方案名称复用现有 WPF 共享动画时钟，通过 SpeedRatio 实时调整速度，保留当前位置；停止、最小化或关闭后释放时钟引用。
- 滚动速度走独立更新路径，避开整套设置的排版、依赖状态、主题、位置和检测刷新。合并调度，忽略未改变的速度，保留异步保存。
- 再次打开设置会显示、恢复并激活已有窗口；可见的最大化窗口保持最大化，不创建重复窗口。
- 单屏时隐藏切屏按钮和副屏说明；保留主屏标准位置与副屏已保存配置。显示器变化沿用已有事件，控件渐隐/渐显带版本守卫；减少同次刷新重复枚举。
- 关闭后拒绝延迟滚动更新，避免重新启动已释放的动画；未新增轮询或计时器。

## 验证与性能边界

相关回归 509 项通过：PerformanceChecks 57、DisplayNotificationChecks 311、SettingsChecks 58、SettingsCardChecks 83。应用编译 0 警告、0 错误。覆盖速度立即生效、共享时钟不被替换、连续速度修改、关闭释放、最小化/隐藏恢复、最大化保持、单屏显示条件与已有通知功能。

200 次速度设置的受控调用对比（同一测试进程，不含异步磁盘完成时间）：完整设置路径约 66.77 ms / 3,077,584 B；独立速度路径约 0.86 ms / 17,600 B。该数字证明调用路径开销降低，不代表整机 CPU 或实际显示帧率同比降低。

相同 Release 测试宿主、192 DPI、16 个逻辑处理器、相同负载，预热 3.5 秒后采样约 15 秒：

| 场景 | CPU 前 / 后 | 平均工作集 MiB 前 / 后 | 平均私有内存 MiB 前 / 后 |
| --- | --- | --- | --- |
| 设置连续滚动 | 0.759% / 0.665% | 360.6 / 352.5 | 297.9 / 289.7 |
| 收起岛文字滚动 | 1.458% / 1.002% | 266.1 / 265.9 | 207.2 / 204.0 |

CPU 为进程 CPU 时间除以总逻辑处理器数。单次样本仍受桌面环境影响，不能据此认定稳定的整体改善；未证明明显内存下降，也不以 WPF 渲染回调间隔推断显示器帧率。实际桌面滚动观感、多屏插拔仍待人工验收。
