# 设置界面下一阶段方案（待视觉验收）

本轮先落地不改变已有操作路径的性能优化。本文件提出下一阶段的界面方向，尚未修改当前设置布局。

## 判断与约束

目前设置把全部分类放进一个长滚动页面。导航能定位，但新用户仍需理解大量开关，窗口也一次创建全部控件。单纯换配色或把高级选项折叠起来，不能解决全部控件常驻的问题。

建议保留现有分类顺序、侧栏收缩、开关卡片、开关与滑条组合、同板块长按排序及动画；先做单分类展示，再在分类内部区分常用设置与高级设置。不要同时重写控件外观和导航，以便定位问题及回滚。

## 推荐的两步实现

1. 侧栏选中哪个分类，右侧就显示哪个分类，首次进入才创建控件，离开后停止动画。位置、外观、组件、行为、提醒、方案、更新顺序不变。分类切换使用原地渐隐和渐显，快速连续切换取消旧动画，保留分类内的滚动位置和组件顺序。
2. 分类内先展示常用项，通过“高级设置”渐进展开其余内容；首次布局直接采用保存状态。高级项的真实设置值继续生效，不能因为控件未创建或未展开而被重置。

## 常用与高级的初稿

| 分类 | 默认展示 | 高级设置候选 |
| --- | --- | --- |
| 位置 | 位置方案、拖动与锁定 | 向上展开回复置顶、越过屏幕边界 |
| 外观 | 颜色模式、大小、文字大小、不透明度、即时预览 | 阴影、细分宽高、额度滚动速度 |
| 组件 | 已安装助手的状态点和额度、托盘图标 | 自动启动及助手专属检测选项 |
| 行为 | 悬停展开组合卡片、反向选择、应用顺序 | 回弹动效与其它次要交互 |
| 提醒 | 任务完成、需要确认、额度重置提醒组合卡片 | 全屏和未变化隐藏策略 |
| 方案 | 三个方案的命名、保存与应用 | 暂不分层 |
| 更新 | 版本、自动检查、检查与安装、项目地址 | 暂不分层 |

以上分类是可讨论的初稿。例如全屏与自动隐藏使用频率可能很高，若实际验收如此，应放回默认展示。不要仅为缩短页面把常用项藏起来。

## 必须保留的行为

- 没安装、未运行、被暂时隐藏是三种不同状态，不能混用；未安装助手的选项置灰并说明原因。
- 开关与滑条组合保留当前悬停展开行为和边框，下方遮挡处理、拖动排序模式及抓取动画均保留。
- 运行、完成、异常、待确认通知优先级及并行任务单项完成提醒不随界面重构改变。
- 更新红点在分类尚未创建时仍能更新；异步刷新不能把焦点或正在拖动的滑条重置。
- 每次可见切换都有过渡；不限制为 30 FPS，不用定时强制 GC 或工作集修剪制造低资源读数。

## 验收与回滚

先给出可交互原型，验收后再迁移现有控件。重点检查 780/920 宽度、200% 缩放、侧栏快速反向切换、分类内排序、未安装状态、设置即时预览及关闭后重开。再以相同条件比较首次打开时间、工作集、私有提交、GC 堆和 CPU。

设置数据继续采用现有字段，首轮不修改配置文件格式；UI 迁移独立提交，可单独 revert。联动板块仍属于后续规划，不在本轮实现。
