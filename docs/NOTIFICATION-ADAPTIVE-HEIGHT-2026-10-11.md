# 通知高度与屏蔽入口调整（2026-10-11）

- 系统通知根据当前批次实际内容占用高度：有正文通常两行，仅标题一行，最高不超过设置的 1–6 行。保留原有逐批显示全部消息的顺序与容量。
- Codex、WorkBuddy 等 agent 的回复、待确认文本仍使用设置的固定行数。
- 批次内容变化沿用高度动画；展开动画过程中切换批次保留版本守卫与完成回调。不新增计时器、轮询、文件读取或长期缓存。
- 永久屏蔽入口改为圆角“不再通知”文字按钮，并同步设置说明。仍仅屏蔽对应来源的相同标题，设置中可恢复；通知点击仍用于打开来源应用。

验证：DisplayNotificationChecks 311 项通过，包括 1–6 行预算、空正文、启动反馈、agent 优先级、逐批顺序、悬停阅读与快速高度切换的动画收尾。此为开发回归检查，不代表真实桌面视觉验收。
