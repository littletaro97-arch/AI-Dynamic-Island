# Magic 菜单修复 · 0.8.0-preview.5

修复范围：Magic 右键菜单右下角矩形边界，以及左键空白处无法关闭。继续使用主程序原有 WPF 菜单外观、圆角、主题、图标与打开过渡；未制作 Release 或修改公开更新清单。

- Magic 菜单关闭系统矩形阴影，保留 WPF 圆角阴影，并为其四周预留 14/14/24/24 DIP 空间，避免阴影被 Popup 边界裁切。普通模式仍使用原有策略，退出 Magic 清除局部覆盖。
- 上一版移除原 WinForms 菜单专用外部点击观察后，仅依赖 WPF StaysOpen=false。在不激活的 Magic 覆盖层入口，该机制不能可靠关闭菜单。现在宿主在菜单打开并完成布局后安装菜单专用鼠标观察，左/右/中键点击菜单圆角实体外侧时排队关闭；阴影空白与圆角空白也属于外部区域。
- 观察器始终调用下一钩子，不主动拦截输入；仅处理按键落下事件，没有鼠标移动处理或轮询。菜单关闭、退出 Magic 后释放钩子；旧观察器已排队的动作不能关闭新菜单。未安装/未启用 Magic 时不创建观察器。
- 钩子安装失败时记录生命周期日志并关闭当前菜单，避免留下无法关闭的弹窗。

后台验证：主程序与适配器编译 0 警告/0 错误；SettingsChecks 83 项通过。新增检查覆盖系统阴影关闭、圆角和阴影留白、内部点击、外部点击去重、圆角空白、关闭后的旧回调，以及普通模式的样式恢复。检查只构造隐藏控件，并使用不安装原生钩子的观察器，未操作桌面输入。

经用户本次明确同意后重启灵动岛、打开 preview.5 并保持运行。真实桌面矩形边界、点击空白关闭、混合 DPI 定位仍由用户验收，不以编译或隐藏测试代替视觉验收。
