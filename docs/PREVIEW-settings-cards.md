# 设置组件迭代验收

2026-10-02，基线 `f5f19d4`，分支 `codex/settings-expandable-sort`。包含上一轮积分、下载进度条和升级目录源码修复。本轮不发布、不生成安装包、不变更公开版本号或更新清单。

行为与其它大板块标题原本同为 18 px/SemiBold；现统一引用 SectionTitle 样式。

“Codex 额度重置提醒”和“状态未变化时隐藏”分别与对应分钟滑条组成完整卡片。关闭时保持普通开关样式；开启、可用且鼠标进入时向下展开。绿色边框包住开关和滑条。滑条沿用外观设置的绿色圆角轨道和白色拖动柄。鼠标进入滑条仍处于卡片内部，不会误收起。

布局保留双列固定槽位：展开只让同列正下方第一个卡片下沉 16 px 并渐隐、暂停命中；其它槽位不动。最后一行展开时只处理板块内紧接其后的第一项；遇到空槽不隐藏更远的卡片。收起时恢复原透明度（包括原有禁用状态），支持快速移入/移出和相邻展开切换。

长按开关卡片 600 ms 进入“组件位置编辑”，上方固定显示完成按钮，也可 Esc 退出。编辑模式内不响应开关点击或键盘开关切换，合并卡片收起滑条；仅支持当前大板块内拖动，跨板块放置被拒绝。顺序保存在 settings.json 的 SettingCardOrders，并保留在方案切换时；旧配置自动沿用默认顺序，新增或失效键不会丢失现有组件。

验证：项目编译；原 SettingsChecks；新增 SettingsCardChecks 覆盖标题一致、关闭不展开、边框内布局、只隐藏下方一项、其它槽位固定、快速反向恢复、编辑阻止展开、板块内排序和跨板块拒绝、顺序键兼容。自动检查不等于真实鼠标验收。

Computer Use 初始化及重置重试均失败，提示“failed to write kernel assets: 系统找不到指定的路径”。本轮无法进行真实窗口自动鼠标验收，交由用户验收长按、拖动、滑条及动画效果。

临时预览目录：`.build-check/settings-cards-preview`，运行 `YoyoClawCompanion.exe --preview`。预览模式保留现有用户配置，不注册此临时目录到开机启动。验收前备份 settings.json 和 presets.json；正常安装版位于 `E:\D-diskExpansionCabin\AI Dynamic Island\Installed\YoyoClawCompanion.exe`。

恢复安装版：退出临时预览后启动上述安装路径。Git 回滚通过 `git revert` 本轮提交。

## 第二轮复用与提示修复

“悬停展开 / 悬停延时”和“任务完成提醒 / 完成提醒时长”也合并为同一展开卡片，复用既有边框、动画、固定槽位与编辑限制。时长范围和原功能逻辑不变；完成提醒时长仍供完成提醒和待确认提醒共用。

移除整片 SettingsSwitchPanel 的系统提示，改为各开关独立的提示控制器：悬停 450 ms 后显示，离开开关立即开始 140 ms 渐隐，不需额外点击；鼠标按下、进入编辑、控件卸载均关闭提示，支持快速返回时旧回调失效。合并卡片仅开关区域触发提示，滑条区域不会保持提示。提示使用当前明暗主题颜色。

SettingsCardChecks 新增两组卡片关闭/展开/边框归属/编辑限制检查，原 SettingsChecks 通过。第二轮预览目录 `.build-check/settings-cards-preview-2`；真实鼠标移开提示和拖动滑条仍待用户验收。

## 第三轮：完整组件隐藏与组合卡片提示

“滚动速度”的标题和值原来在 DockPanel，滑条是其后的独立 Slider。展开悬停设置时只渐隐了前者，导致整行滑条残留。现将标题、数值、滑条放入同一个 QuotaScrollSpeedPanel，作为完整的下方组件统一下沉、渐隐及恢复；不改变其原宽度和数值范围。

所有 ExpandableSettingCard（开关＋滑条）不再注册长按提示，关闭和展开状态都不显示提示；长按排序能力保持。普通开关仍显示移开后渐隐的提示。

SettingsCardChecks 新增整行组件宽于组合卡片、标题和滑条属于同一容器、整体渐隐和恢复、组合卡片未注册提示的检查。第三轮预览目录 `.build-check/settings-cards-preview-3`。
