# 反向选择与悬停展开独立设置

取消设置事件中的互相取消勾选，以及配置/方案规范化时自动关闭悬停展开的规则。两个开关独立保存。

- 悬停开启、反向关闭：普通悬停展开。
- 两者开启：收起时普通移入隐藏；按住 Alt 后按设定延时悬停展开，Alt 点击立即展开；松开 Alt 不隐藏已经展开的岛。
- 仅反向开启：Alt 暂停隐藏，悬停展开功能仍关闭。
- 两者关闭：不自动悬停展开。

展开入口共用 CanPointerExpand 判断。Alt 恢复隐藏岛时也安排悬停计时，松开时取消未完成的展开计时。明确点击可覆盖“手动收起后等移出才允许悬停重开”的保护，但收起横条与拖动不被误当作展开点击。保留通知强制展开、悬停阅读、展开动画和 guardian 来源过滤；不新增轮询或键盘注入。

DisplayNotificationChecks 273、SettingsChecks 58、PerformanceChecks 49 项通过，共 380 项。覆盖同时开启的 Alt 条件、配置规范化保留两开关、Alt 点击、手动收起后明确重开、松开后展开保持和关闭悬停的情况。真实按键/鼠标仍须用户验收。本轮仅本地提交与切换验收版，不发布 GitHub。
