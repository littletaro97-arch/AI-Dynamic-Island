# 悬停阅读时暂停提醒倒计时

基线为本地 `e705e17`。旧显示定时器到期直接结束提醒：鼠标悬停虽能阻止普通收起，却不能保留通知内容或阻止下一批切换。

系统通知、任务完成、额度预告和共用显示计时的待确认提醒统一采用剩余时长计时。鼠标进入展开岛时停止原定时器并保存剩余时间；离开后继续剩余时间，不重新给予完整时长。提醒到达时鼠标已在展开岛上，或者展开动画使鼠标位于岛内，也会立即暂停。停止期间保持当前批次，后续通知继续排队；主动点击底部横条仍可取消活动提醒和积压通知。

使用单调 Stopwatch 记录未悬停期间的时间，只在进入、离开和原定时器到期时计算。不增加常驻定时器、逐帧回调、配置项、文件读取或写入。旧的到期回调不能提前结束新启动或恢复的批次；关闭窗口、主动收起、确认解除和相关清理路径重置时钟。修改显示时长仅影响后续提醒，当前暂停或运行中的提醒保留自己的剩余时间。沿用原展开、收起与批次渐显动画。

Release 构建无警告/错误。DisplayNotificationChecks 250 项、PerformanceChecks 49 项通过。新增检查覆盖悬停超过预设时长、保持当前通知与待显示批次、到期回调保护、移开继续剩余时间、反复悬停、正常进入下一批、手动收起不重启、强制收起恢复计时，以及鼠标已在岛内时的新完成/系统预告提醒。这是离屏事件和控件验证，不代替实际鼠标阅读验收，也没有据此声称 CPU 百分比下降。

本轮仅本地提交、编译与启动验收版，不推送 GitHub、不生成正式安装包、不改变发布版本号。验收：通知到达后停留鼠标超过显示时长，当前正文应保留；移开后按剩余时间结束或展示下一批；悬停时点击底部横条应正常收起。
