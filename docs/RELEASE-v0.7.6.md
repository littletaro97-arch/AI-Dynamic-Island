# AI Dynamic Island v0.7.6

稳定版小版本更新。

- 修复应用常驻跨日或休眠恢复后 YOYO 自动签到没有再次触发的问题。复用现有刷新机制，每日最多三轮，失败后分别等待 5 分钟、30 分钟；成功后当天停止，记录不包含账号凭据。
- 状态快照和高频配置保存改为后台合并写入，等待队列有界；保存配置时保留版本顺序和退出保底，状态文件使用临时文件替换，避免读到半份数据。
- 设置界面和灵动岛复用未变化的主题资源，减少连续调整设置时的无效刷新。保留原动画、检测频率与清晰度。

CPU/内存的整应用改善仍需相同负载实测，局部写入测试不代表整应用资源降幅。Windows 通知权限、微信通知来源限制以及独占全屏覆盖限制与上一版本一致。
