# AI Dynamic Island v0.7.1

- 设置分类调整为：位置、外观、组件、行为、提醒、方案、更新。
- 左下角可收缩导航，保留图标及提示；加入目录宽度、原地文字淡入淡出和箭头旋转过渡，品牌图标位置固定。
- 修复更新导航图标底部裁剪。
- 反向选择移入行为，与悬停展开互斥；兼容旧配置和保存方案。
- 未安装应用的对应功能置灰，拖动排序仅显示已安装应用，保留隐藏应用顺序。
- 修复单文件发布遗漏 YOYO 桥接及第三方许可文件的问题，增加发布资源检查。
- 统一 EXE、快捷方式、窗口、托盘及安装器图标；新安装目录不再追加 Installed。

安装版用户可在设置 → 更新中检查并下载安装；升级沿用原安装目录和用户配置。新安装选择 setup.exe，便携使用选择 portable.zip。

支持 Windows 10/11 x64；包内含 .NET 桌面运行时，YOYO 桥接仍需 Node.js。
