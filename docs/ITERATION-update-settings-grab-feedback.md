# 更新设置与卡片抓取反馈（本地迭代）

日期：2026-10-02。基线：v0.7.2 发布后的 `92a5cc2`。分支：`codex/update-settings-grab-feedback`。

本轮保持版本号 0.7.2，只提交本地源码，不生成安装包/便携包，不推送、不修改公开更新清单。

- 设置窗口打开时读取已有更新状态；有新版本时，目录“更新”的 GitHub 图标右上角显示 7 px 红点。后续检查结果驱动渐显/渐隐，连续反向状态不会被旧回调覆盖，目录收缩时仍显示。
- 检查更新和下载安装按钮移至自动检查开关右侧同一行。底部显示项目地址，提供默认浏览器跳转及复制地址，复制结果渐显反馈；失败显示可操作提示。
- 长按进入位置编辑或编辑期间按下卡片时，该卡片围绕中心平滑缩小到 94%。换位平移动画独立保留缩放，松手、取消拖动或退出编辑时恢复。
- 悬停延时保留下限 20 ms，上限改为 130 ms，步长 5 ms；滑条吸附档位，方向键和大步进同为 5 ms。配置、方案和运行时读取统一归一化，旧值越界夹取，非档位数值就近取整，非有限值回到默认 70 ms。

验证：运行 SettingsChecks、SettingsCardChecks，覆盖更新红点初始/反向状态、780/920 px 窗口按钮布局、档位与旧设置归一化、抓取动画/换位并存/松手恢复和既有设置交互，均通过。代码差异检查通过。

上述检查包含测试项目的常规编译，不是正式版本构建。真实鼠标视觉验收、默认浏览器跳转及系统剪贴板操作尚未由用户验收。本轮没有替换或重启已安装应用。

回滚可对本轮提交执行 `git revert`，不修改现有发布标签和安装目录。
