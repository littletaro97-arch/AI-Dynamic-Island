# 菜单与说明卡片复用、状态逻辑检查

基线为本地 `5062531`，分支 `codex/shared-settings-descriptions`。仅源码迭代和本地验收，不更改公开版本号、安装包、更新清单或 GitHub。

## 界面复用

屏蔽通知恢复菜单改为设置界面样式。现有下拉框与恢复菜单共用 `SettingsPopupSurface` 和 `SettingsPopupItemSurface`，包含圆角、边框、背景、阴影、项目间距和主题资源；恢复菜单取消系统默认图标槽，长标题省略，保留完整提示与精确规则身份。沿用渐显，增加项目悬停过渡。

`ExpandableSettingCard` 统一支持开关、按钮入口及说明内容，使用同一套高度、渐隐、绿色包边和快速反向切换保护。说明可按宽度测量高度，滑条卡片保留既有开关开启后才能展开的规则。

- “关闭系统弹窗”仍是 Windows 设置入口，复用按钮标题卡片，悬停显示通知开关与请勿打扰说明。没有制造未经系统验证的开关状态，也不直接修改 Windows 设置。
- 全屏说明移入“全屏时活动显示”卡片，悬停即可阅读，即使当前未开启也不改变开关值。编辑位置时不展开。
- `SettingsSwitchPanel` 共用一列和两列布局，保留稳定槽位：展开全宽说明只让下方第一行下沉渐隐，其余内容保持位置。按钮入口没有启用长按排序，也不启动多余的长按计时。
- 保留原开关名字作为排序键，已有位置方案继续有效；复用卡片不出现遮挡内容的长按提示。

## 检查与精简

| 检查区域 | 处理结果 |
| --- | --- |
| 通知分批、规则屏蔽与恢复 | 保留批次容量、来源点击身份、具体标题过滤及原通知中心内容。共享丢弃本轮通知逻辑，避免重置时留下没有计时器的活动通知。 |
| 悬停计时、主动收起及待回答优先级 | 保留悬停暂停、移开继续剩余时长、主动取消及高优先级提醒中断机制。 |
| 关闭与后台刷新 | 统一停止轮询和临时交互定时器；启动、刷新和重新检测的异步恢复点增加关闭检查，避免晚到结果更新已关闭界面或重启定时器。 |
| 卡片编辑与动画 | 取消重复进入同一编辑状态的动画；排序前收起并恢复覆盖项；卸载时取消说明动画和订阅，保留拖动跟随及排序行为。 |
| 助手检测与额度 | 保留并行任务完成、WorkBuddy 中途文本判定、Codex 待回答、重置预告去重、YOYO 多批积分与 DeepSeek 状态判定；用现有回归覆盖，不重写解析器。 |
| 多屏、更新和程序路径 | 保留屏幕锚点、断开回退、长名称省略、安装/便携选包与摘要校验；本轮不改变发布流程。 |

精简重点是消除独立样式和重复生命周期处理，新增功能仍需要少量通用参数及回归代码；不以减少总行数为理由删除诊断或已有功能。新增说明没有轮询或逐帧 Dispatcher 回调，隐藏时的控件动画停止，不降低静态文字清晰度。

推荐后续优化：诊断 `status.json` 仍在刷新期间同步写盘，可单独考虑后台合并、原子写入，并进行相同负载的前后测量；本轮没有改动它的读取契约，未声称 CPU 百分比下降。

Release 构建无警告/错误。8 组现有检查合计 1114 项通过：SettingsCardChecks 78、DisplayNotificationChecks 253、SettingsChecks 58、PerformanceChecks 49、ActivityChecks 640、WorkBuddyCompletionChecks 17、QuotaChecks 7、UpdaterChecks 12。

新增检查涵盖浅深色菜单共享资源、具体恢复规则身份、按钮入口保持语义、说明包边、稳定后续布局、快速悬停反转、编辑状态约束、卸载清理、重置丢弃通知、窗口关闭停止所有定时器和拒绝延迟刷新。离屏截图使用虚构通知来源；未自动发送消息、打开系统设置或执行真实更新安装。自动检查不代替鼠标、真实消息、游戏全屏或实际升级验收。

验收：恢复菜单应与现有下拉框一致；悬停系统通知设置入口与全屏开关时说明渐显，移开渐隐；快速进出、开关编辑、浅深色切换、通知悬停阅读和窗口关闭均应保持原有交互。
