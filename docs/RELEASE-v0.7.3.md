# AI Dynamic Island v0.7.3

本次为 v0.7.2 的小版本更新，提供 Windows x64 安装版和便携版。

- 修复 WorkBuddy 中途文本被误判为任务完成、提前展开灵动岛的问题。核验最终答复的结束元数据，中途文本保持执行中；真正完成才提醒。
- 支持并行任务单项完成提醒：有其它任务运行时，顶部保持执行状态，展开告知已完成的任务。
- 新增 DeepSeek Harness 状态检测，支持执行、完成、异常和待决策。
- 支持暂时隐藏未运行助手的检测信息与状态点，该助手重新运行后恢复；修复隐藏后的文本重叠、四个状态点对齐及长名称过早省略。
- 更新分类支持新版本红点；检查和安装按钮移至自动检查右侧，提供项目地址跳转、复制，修正按钮对齐。
- 长按排序增加抓取及随鼠标移动的效果；悬停延时范围为 20–130 ms，步长 5 ms。
- 降低重复检测与日志解析分配，停止不可见方案名称的滚动动画；缓存岛的阴影，减少文字滚动时的重绘开销。

两种下载包均包含 .NET 8 Desktop Runtime，沿用用户设置和现有安装升级路径。YOYO 桥接仍需本机 Node.js；Harness 检测需要 Harness 自带运行时。未安装某个助手不影响其它来源。

受控长文字滚动场景平均 CPU 约 2.75% → 1.56%，私有提交约 275.5 → 250.1 MiB；这不是完整应用的日常平均占用保证。阴影分层使半透明背景略亮，已纳入本地验收。详见 [性能验证](PERFORMANCE-2026-10-03.md) 和 [WorkBuddy 修复验证](WORKBUDDY-COMPLETION-2026-10-03.md)。

设置界面下一阶段的单分类展示及常用/高级分层、Bilibili-monitor 联动仍处于规划阶段，本版本没有重构设置导航或实现联动板块。
