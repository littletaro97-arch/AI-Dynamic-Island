# AI Dynamic Island v0.7.2

本次为 v0.7.1 的修复与设置体验更新。

- YOYO 积分支持有效批次汇总，并使用较新的官方账单记录补足过期本地快照导致的积分漏算。
- 更新下载进度条统一为圆角灰底、绿色填充，并支持平滑过渡。
- 安装版升级明确复用已注册目录，同路径跳过目录选择，保留首次安装/换目录的正常确认；开启安装日志。
- 设置标题统一样式，四组开关和对应滑条合并为悬停展开卡片：悬停展开、任务完成提醒、额度重置提醒、状态未变化时隐藏。
- 展开时下方第一项整体下沉渐隐，其余位置固定；整行设置的标题与滑条一同隐藏、恢复。
- 长按 600 ms 可调整同板块内开关卡片顺序，编辑时禁用开关点击并收起滑条，顺序保存在配置中。
- 普通开关提示移开后渐隐，组合卡片不显示长按提示，避免遮挡。

提供 Windows x64 安装版和便携版，均包含 .NET 8 运行时。配置保留，开机启动路径不指向临时预览目录。

联动板块仅完成规划，v0.7.2 未实现；详见 docs/INTEGRATION-PLAN.md。

编译、积分解析、设置控件及更新服务回归通过；安装器编译通过。发布后验证匿名更新检查与两个下载资产校验，实际 v0.7.1 → v0.7.2 安装升级由用户验收。
