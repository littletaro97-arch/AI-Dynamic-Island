# Magic 视界主程序集成：本地验收 0.8.0-preview.1

基线为正式源码 f927e5b / 0.7.7，显示实现来自用户验收过的独立实验 0.0.5。本次只构建本地验收程序，不修改公开更新清单，不生成安装包、标签或 GitHub Release。

## 实现边界

- MagicStatusbarAdapter 是单独的显示程序集，通过延迟加载接入主进程。未安装或关闭开关时不加载它和 MagicBarLayout.dll，也不创建适配窗口、UIA 工作线程、钩子及定时器。安装识别在后台进行；后续运行识别复用原有应用进程快照。
- 已安装且开启开关时，有 Magic 顶部栏才进入适配。智能隐藏和全屏遮挡只隐藏状态行并暂停阅读计时；退出 Magic 或关闭开关会停止、释放适配资源并恢复普通岛。
- 不修改 Magic 的安装文件和设置，不嵌入或注入其进程。
- 状态与系统通知复用主程序已有采集、权限和过滤；不存在第二份托盘、恢复进程、文件观察器或通知监听。Codex 分页记录支持接入公共状态服务，在两种显示模式共用。
- 延续顶部居中、两侧避让、白色 #F7F9FC、简称和省略号、同来源一轮通知、不延长当前轮次、待回答优先与队列恢复。不显示时间，保留左键应用跳转和右键菜单。
- 设置增加自动适配开关、当前状态、每轮通知时长、闪烁周期。默认关闭；本次验收启动参数 --magic-preview 开启当前实例，以便直接体验。普通模式位置、大小、展开等配置不覆盖，Magic 模式下禁用对应操作并显示原因。

## 验证

- 编译成功，零警告、零错误。
- MagicChecks：58 项，覆盖实际集成模型的连续来源合并、固定模式避让、队列与隐藏恢复、周期参数、分页提问及答复。
- SettingsChecks：普通设置回归及新增模块加载边界通过；在真实 Magic 进程存在时，主进程内启动适配成功，关闭后确认 UIA 工作线程释放、Form 及渲染定时器释放。
- CodexDecisionChecks：11 项；PersistenceChecks：14 项；DisplayNotificationChecks 通过；最终 ActivityChecks：649 项通过。
- 实际进程关闭状态，适配程序集与原生 DLL 加载计数均为 0；开启状态均为 1。最终程序保持运行；独立实验和旧版主程序已退出。
- 桌面截图核对顶部居中、文字配色和左右图标避让；此项不替代用户对显隐、点击、通知轮播的实屏验收。

## 成本和限制

新增分发的两份 DLL 当前构建合计 188,928 字节，约 184.5 KiB（不含源码、调试符号及未来打包元数据）。未启用不产生模块运行资源，但这些文件仍占安装空间。

同一优化构建、同一屏幕与设置窗口打开情况下，各取 15 秒进程样本：

| 模式 | 工作集 MiB | 私有内存 MiB | CPU 秒 | 线程 | 适配 DLL / 原生 DLL |
|---|---:|---:|---:|---:|---:|
| 关闭 | 390.76 | 280.04 | 1.641 | 53 | 0 / 0 |
| 开启 | 386.37 | 266.39 | 1.391 | 55 | 1 / 1 |

短样本来自不同启动实例，状态采集和 JIT/GC 的差异仍存在；不能把负差值当成性能优化，也不能据此声称适配零额外成本。可确认没有新增常驻进程，模块只在开启时加载。关闭后线程、钩子和窗口释放；已加载的程序集及 DLL 映射可以保留到主程序退出，不声称热关闭后所有代码映射均卸载。

本轮桌面验证为当前单一顶部栏；Magic 多屏顶部栏、其他安装版本的控件布局仍需实机验证。普通模式原有更新与发布流程保留。

本地启动：YoyoClawCompanion/bin/Release/net8.0-windows10.0.19041.0/YoyoClawCompanion.exe --preview --magic-preview。
