# AI Dynamic Island v0.7.5

本次小版本更新提供 Windows x64 安装版和便携版，沿用已有设置及安装目录。

- 系统通知按回复行数分批显示：6 行每批 3 条，4–5 行每批 2 条，依次展示；每条可打开自己的来源应用。
- 鼠标停留在展开岛时暂停提醒倒计时，移开后继续剩余时间，避免阅读时收起或切换消息。
- 通知旁的 × 可屏蔽该来源的具体标题；设置中可恢复。适用于持续更新的常驻通知，原通知中心内容保留。
- 反向选择与悬停展开改为独立开关。同时开启时，普通移入收起岛会隐藏；按住 Alt 可悬停或点击展开。展开岛不会因松开 Alt 隐藏。
- 统一文字最小字号为 12 DIP，改善说明间距，复用浅深色菜单和悬停展开说明卡片。
- 修复 Codex 同周期额度预告因时间抖动、重启而重复提醒；排除内部 guardian 审批会话的错误完成提醒。
- 修复 WorkBuddy 大工具返回被跳过导致任务完成后仍显示执行中；显示积分读取的连接权限错误。
- 整理窗口、通知和动画生命周期，避免关闭后晚到刷新重启计时器。

通知监听需要 Windows 通知访问权限，只覆盖提交到通知中心的 Toast。QQ/微信托盘唤起使用本机配置的 Ctrl+Alt+X / Ctrl+Alt+W；通知接收与应用唤起是不同能力，未提交到通知中心的微信弹窗无法保证同步。

WorkBuddy 和岛建议使用相同的普通用户权限；管理员运行的宿主可能拒绝普通权限积分通道。程序不会自行提权或更改宿主访问控制。关闭系统弹窗入口仍打开 Windows 设置，由用户选择请勿打扰，保留通知总开关。

两种包包含 .NET 8 Desktop Runtime；YOYO 桥接仍需本机 Node.js。没有宣称所有设备的 CPU/内存占用下降。Bilibili-monitor 联动仍处于规划阶段。
