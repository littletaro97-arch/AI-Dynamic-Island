## 性能改动与原因

1. **避免为渲染变化检查序列化整个快照。** RenderStamp 比较实际显示字段、几何与点击身份。预览正文、完成时间、通知到期时间变化不再生成 JSON 长字符串或重画像素；标题、应用标识变化仍刷新点击行为。
2. **复用测量资源。** 字体、1×1 测量画布、Graphics、StringFormat 和白色画刷仅在需要时创建，DPI 变化时重建字体，退出时释放。
3. **复用原生像素表面。** PixelSurface 保存一个匹配尺寸的顶向下预乘 Alpha DIB 和内存 DC。过渡期间直接复制像素，减少逐帧 GetHbitmap、创建/销毁 DC 和 HBITMAP 的成本。500 次提交期间 DIB 创建计数保持 2→2。
4. **复用过渡位图。** 过渡期间复用混合缓冲区，尺寸变化时重建；静态透明度变化复用已上传表面。隐藏过渡结束后释放当前、旧、混合位图和 DIB，恢复显示时重新生成；关闭时释放字体、钩子、布局工作线程和所有渲染计时器。
5. **减少重复布局回调。** UIA 属性/结构事件只唤醒布局工作线程；只有安全边界、可见性或 HRESULT 变化才回调 UI。查询耗时、控件数量改变但占用边界相同，不重复分派更新。WinEvent 和 150ms 显隐后备检测保留。
6. **减少几何与命中分配。** 未变化的窗口矩形/DPI 不再创建 Window 记录；命中判断直接遍历少量区域。

这些修改没有新增独立采集器、子进程或依赖包。未安装或关闭 Magic 的程序集/native DLL 不加载边界已有控件检查继续通过。

## 前后专项测量

基线是修改前 preview.3 模块的副本。两者使用 Release、192 DPI、3072×64 原生栏几何，同一隐藏窗体、三助手快照、两段各 2000 字符的附加正文；不显示桌面窗口。交替运行三次，以下为中位数。

| 指标 | 修改前 | 最终版本 |
| --- | ---: | ---: |
| 10,000 次未变化 Render 耗时 | 48.40 ms | 1.96 ms |
| 10,000 次未变化 Render 托管分配 | 180,400,952 B | 744 B |
| 500 次过渡 Submit 耗时 | 676.22 ms | 525.39 ms |
| 500 次过渡 Submit 进程 CPU 时间 | 0.70312 s | 0.59375 s |
| 500 次过渡 Submit 托管分配 | 216,696 B | 220,696 B |
| 隐藏基准进程：Render 阶段私有内存 | 29.71 MiB | 13.80 MiB |
| 隐藏基准进程：Submit 阶段私有内存 | 31.31 MiB | 16.68 MiB |

过渡提交耗时下降约 22.3%，CPU 时间下降约 15.6%。未变化路径的 CPU 时间短于计时粒度，读数 0 不代表绝对零成本。过渡阶段托管分配增加 4,000 B（约 1.8%），没有把这一指标描述为改善。为了避免重建，显示期间会保留一份混合位图；980×64 像素时约 0.24 MiB，隐藏后释放。

这些是渲染专项压力测试，包含基准宿主的 .NET/WinForms 成本。180 MB 是累计托管分配而不是瞬时占用，MiB 值是基准进程当时的私有内存，不是 Magic 组件的独占内存。不据此推算整程序 CPU/内存减少百分比，也不把提交耗时当作显示器实际 FPS。

## 真实进程采样

用户明确许可后打开最终验收版本，保持当时桌面/应用状态，以 3 秒间隔采样 10 次，约 30.2 秒：

- 主进程平均 CPU：整机 0.56%（16 个逻辑处理器；单核口径 8.89%）。
- 私有内存平均 330.4 MiB，范围 327.5–332.5 MiB。
- 工作集平均 442.2 MiB，包含共享 DLL、原生/UIA/WPF 内存；不等同于托管堆。
- 10 次响应状态均正常；适配器与原生布局 DLL 已加载，生命周期日志确认主屏原生栏连接与显示。

开始检查时没有正在运行的主程序旧实例，因此没有同场景旧版整体基线。用户正在使用电脑，助手工作和通知状态也会影响结果。此次真实采样只能说明当前占用，不能证明整程序减少了多少。较高的整体内存还需在相同助手/通知/设置窗口状态下进一步对照，渲染专项结果不替代该对照。

复现专项基准：

```powershell
dotnet run --project tests/MagicRendererBench/MagicRendererBench.csproj -c Release -- <模块DLL绝对路径> <标签>
# 可选第三个参数为离屏渲染图片输出目录；--repeat 则在同一进程重复五轮资源检查。
```

SettingsChecks 默认只进行隐藏控件检查；真实 Magic 连接需要显式 --live-magic，离屏证据窗口需要 --layout-evidence。运行涉及真实桌面/重启的检查前仍遵守用户当次授权。

本次没有替用户切换固定/智能隐藏模式、点击通知或打开应用；这些视觉和真实交互由用户验收。验收程序保持打开，安装目录和正式发布包未替换。
