# AI Dynamic Island v0.7.4

本次为小版本更新，提供 Windows x64 安装版和便携版，沿用已有配置和安装位置。

- 新增主屏/副屏独立位置设置与六个标准锚点，自动识别横竖屏，副屏断开时回退到主屏。
- 新增 Windows 系统通知同步与独立显示时长，通知展开时显示消息来源和正文，点击正文可唤起来源应用，保留原系统通知。
- 新增 Codex 中途询问提醒，与其它助手的待确认提醒保持一致。
- 修复反向选择模式下，任务提醒展开后点击横条却使整个岛隐藏的问题：展开时不执行悬停隐去，横条只收起，鼠标移开后恢复反向选择。
- 通知点击优先复用已运行实例，避免额外启动登录窗口。QQ/微信藏在托盘时分别使用 Ctrl+Alt+X / Ctrl+Alt+W，请确认本机对应快捷键与此一致。失败时保留通知并提示从托盘打开，不再强制显示隐藏窗口。
- 优化设置滚轮缓动和运动期间有界缓存，避免 UI 线程批量转换通知。缓存具有额外内存代价，不承诺完整应用在所有环境下占用下降。
- 修复设置中 DeepSeek Harness 长名称遮挡程序路径的问题。

通知监听需要 Windows 通知访问权限，只覆盖通知中心 Toast；本机事件订阅不可用时降级为启用期间约每 2 秒检查，通知可能存在延迟，短暂消失的通知不保证捕获。来源应用的聊天对象跳转、图片及交互按钮仍需原应用处理。

已知问题：Codex 额度重置提醒可能因重置时间秒级变化、重启或重新检测重复触发；本次按用户要求仅排查，未修复。Bilibili-monitor 联动仍处于规划阶段。

两种包均包含 .NET 8 Desktop Runtime；YOYO 桥接仍需要本机 Node.js。实际安装升级、不同机器的快捷键和桌面交互仍以用户验收为准。
