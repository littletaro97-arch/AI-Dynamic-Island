# AI Dynamic Island v0.7.7

稳定版小版本更新。

- 修复 Codex 已取消问题并结束任务后，“待回答”状态仍然残留的问题。
- 系统通知按当前批次实际需要的行数显示，高度不超过设置上限；agent 回复仍保留设置行数。
- 通知屏蔽按钮改为小圆角长方形“不再通知”，明确其持续屏蔽作用，设置中仍可恢复。
- 修复滚动速度需展开、收起后才生效的问题。调整速度立即作用于正在运行的动画，保留滚动位置；精简无关布局刷新，复用共享动画时钟。
- 再次打开设置会恢复已有的最小化或隐藏窗口，保留可见窗口的最大化状态。
- 无副屏连接时隐藏切屏入口和副屏说明，保留副屏已保存的位置。

相关开发回归和受控性能检查通过。速度设置路径的处理耗时和分配量下降；CPU/内存测量受负载影响，不承诺整机资源同比下降。通知来源、Windows 权限及独占全屏限制保持不变。

安装版可通过应用内“检查更新 → 下载并安装”升级；便携版请完整解压后运行。原设置与预设保留。
