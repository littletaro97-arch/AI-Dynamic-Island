爪印旋转 = 忙碌中（1.4s linear infinite，仅 center-mix 模式出现）—— 用"运动"表达进行中，不去抢颜色的活。
几何：r=14.5、stroke-width=2、周长 C=2πr=91.106，stroke-dasharray = "C×比例 C"（空段取整周长，尾段不会绕回来）。
起点方位已实测确认，不是推算：路径原生 p(0)=(30.5,16) 是 3 点、p(1/4)=(16,30.5) 是 6 点（屏幕上顺时针）；配 transform: rotate(-90deg)（matrix(0,-1,1,0,0,0)、transform-origin: 16px 16px）后换算成屏幕方位 = p(0)→0.0°（12 点）、p(0.06)→21.6°、p(0.5)→180.0°，即从 12 点起顺时针。

圆心 · 延时信号格v5 新增，取代常驻爪印。亮的格数 = 到 AI 服务商的网络延时档位，读法照搬手机状态栏。
数据源：TCP 握手到 AI 服务商 base_url 的往返。该 URL 由 SDK 的 provider.list 给出（本机 https://api.moonshot.cn/v1），不要硬编码。system.ping 不能用 —— 那是本机 gRPC，实测中位 5ms，永远满格；provider.healthCheck 语义对但目前返回 Provider authentication failed.，取不到数。
阈值必须按本机基线自己定，别抄 Clash：实测 30–36ms 稳定（首次 55ms 是 DNS 冷启动），所以 ≤60→4 格 / ≤120→3 / ≤250→2 / ≤600→1 / 其余 0。Clash 探的是境外 gstatic/204，天然 100–300ms，照抄会把一切都判成"优秀"。⚠️ 这四个数是按当前网络拍的，用几天后按体感校准。
格色同样遵守"颜色只在该报警时出现"：4/3 格 = 主题紫（安静），2 格 = 琥珀，1 格 = 红，0 格 = 退暗。
零格时必须能分出"没在跑"和"连不上"：前者退灰 rgba(255,255,255,.13)，后者退暗红 rgba(242,104,111,.42)。环色虽然也能区分，但那要用户来回比对两个元素，圆心自己说明白更省事。
几何：4 条竖条、宽 3 / 间距 1.2 → 总宽 15.6；底边对齐 y=15、高 4/7/10/13.5 递增、rx=0.9；装在与爪印同一个 17×17 盒里（inset:7.5px 居中于 32px 圆）。未亮的格留极暗轮廓做基准，否则只剩 1 格时读不出分母是 4。
